## วิธีใช้

1. ใน Obsidian vault (`D:\back up\รายงานและข้อเสนอแนะ กสม`) สร้างโฟลเดอร์ระดับบนสุดตามชื่อในตารางข้างต้น
   **ต้องขึ้นต้นด้วยเลข 2 หลักตามตาราง** (เช่น `06 ...`) ส่วนที่เหลือของชื่อจะเป็นอะไรก็ได้ —
   ระบบดูแค่ 2 ตัวอักษรแรกของชื่อโฟลเดอร์เพื่อจับคู่หมวด
2. คัดลอกไฟล์เทมเพลตที่ตรงกับหมวดนั้นเข้าไปในโฟลเดอร์ที่สร้าง แล้วเปลี่ยนชื่อไฟล์เป็นชื่อเอกสารจริง
3. แก้ไขเนื้อหาในไฟล์ตามคำอธิบายในวงเล็บ `[ ... ]` แล้วลบวงเล็บออก (ทำได้กี่ไฟล์ก็ได้ ไม่ต้องรอให้ครบ)
4. เมื่อใส่ข้อมูลแล้ว รัน `python setup_obsidian_index.py` เพื่อ reindex — เอกสารใหม่จะขึ้นในหน้าเว็บ
   (แถบเมนูซ้ายจะเห็นจำนวนที่ไม่ใช่ 0 แล้ว) โดยไม่ต้องแก้โค้ดเว็บเพิ่ม

## รูปแบบไฟล์ (สำคัญ ห้ามข้าม)

- **บรรทัด YAML frontmatter** (ระหว่าง `---` คู่แรก) ใช้เก็บ tag ที่คัดสรรแล้ว — มีผลต่อการค้นหา ควรใส่ให้ครบ
- **บรรทัดตัวหนา** ใต้หัวข้อ `#` (เช่น `**ปีที่ประกาศใช้ (พ.ศ.):** 2560 · **หน่วยงานที่รับผิดชอบ:** ...`)
  จะถูกดึงไปแสดงเป็นกล่อง "ข้อมูลเอกสาร" บนหน้าเว็บโดยอัตโนมัติ — ใส่กี่ช่องก็ได้ คั่นด้วย ` · `
  แต่ต้องอยู่บรรทัดแรกสุดหลังหัวข้อ `#`
- หัวข้อ `## สาระสำคัญ` ควรมีเสมอ (ใช้เป็นสรุปในรายการค้นหา)
- หัวข้อ `## คำสำคัญ` ใช้แสดงเป็นแท็กบนเว็บ ไม่ถูกนำไปแสดงเป็นเนื้อหาส่วนหนึ่ง
- หัวข้อที่ขึ้นต้นด้วย `## ลิงก์...` (เช่น `## ลิงก์กฎหมายฉบับเต็ม`) จะกลายเป็นปุ่มลิงก์แทนข้อความ —
  ใส่ URL เต็มไว้บรรทัดถัดไป
- หัวข้อ `## ประเด็นสิทธิที่เกี่ยวข้อง` (ถ้ามี) ใช้ลิงก์ `[[ชื่อไฟล์ประเด็น|ชื่อที่แสดง]]` ไปยังโน้ตใน
  `02 ประเด็นสิทธิ` เพื่อให้เอกสารนี้โยงเข้ากราฟประเด็นสิทธิได้เหมือนกรณีตรวจสอบ (ไม่ใส่ก็ได้)

และ `web/src/app/case/[id]/page.tsx` (`parseGeneralMetadata`, `splitGeneralSections`)
