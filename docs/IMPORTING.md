# การนำเข้าเอกสารสู่ Human Rights Knowledge

ระบบเก็บข้อมูลที่ค้นได้ไว้ใน Supabase จึงไม่จำเป็นต้องเก็บคลังเอกสารทั้งหมดบนเครื่องผู้ใช้ หลังนำเข้าสำเร็จสามารถย้ายหรือลบไฟล์ต้นทางจากเครื่องได้ตามนโยบายสำรองข้อมูลของหน่วยงาน

## วิธีที่ใช้ได้ในขณะนี้

1. ส่งหรือแนบไฟล์ `.md`, `.docx` หรือ `.pdf` พร้อมระบุประเภทเอกสาร ปี หมวดสิทธิ และ URL ต้นฉบับถ้ามี
2. ผู้ดูแลตรวจว่าไฟล์ไม่มีข้อมูลส่วนบุคคลหรือข้อมูลลับที่ห้ามเผยแพร่
3. แปลงเนื้อหาเป็นส่วนย่อยโดยรักษาเลขหน้าและหัวข้อ
4. ตรวจชื่อเรื่อง เลขเอกสาร หน่วยงานเจ้าของเอกสาร และสถานะอำนาจของแหล่งข้อมูล
5. นำ metadata และข้อความขึ้น Supabase ด้วยสถานะ `draft`
6. ตรวจตัวอย่างหน้าและ citation แล้วจึงเปลี่ยนเป็น `published`

เอกสาร Markdown ของรายงาน กสม. ที่มีเครื่องหมาย `PageNumber` สามารถเตรียมข้อมูลด้วย `scripts/prepare_markdown_seed.py` ซึ่งสร้างคำสั่งแบบ idempotent จึงนำเข้าไฟล์เดิมซ้ำเพื่อแก้ไขได้โดยไม่สร้างเอกสารซ้ำ

## ข้อมูลที่ควรส่งพร้อมไฟล์

- ชื่อเอกสารและเลขที่เอกสาร
- วันที่หรือปีเผยแพร่
- ประเภทเอกสาร
- หมวดสิทธิที่เกี่ยวข้อง
- หน่วยงานเจ้าของเอกสาร
- URL เอกสารต้นฉบับ
- ระดับการเข้าถึง: public, internal หรือ restricted
- หมายเหตุเรื่องข้อมูลส่วนบุคคลหรือข้อจำกัดการเผยแพร่

## หลักความปลอดภัย

- ห้ามใช้ publishable key เขียนข้อมูลจากหน้าเว็บสาธารณะ
- การนำเข้าต้องทำผ่านบัญชีผู้ดูแลหรือระบบหลังบ้านที่ยืนยันตัวตน
- เอกสารภายในและเอกสารจำกัดสิทธิต้องไม่ถูกค้นผ่าน public API
- เก็บ checksum เพื่อป้องกันไฟล์ซ้ำและใช้ตรวจสอบการเปลี่ยนแปลง
- ควรมีขั้นตอนอนุมัติก่อนเปลี่ยนสถานะเป็น published

## ขั้นถัดไปสำหรับการนำเข้าแบบบริการตนเอง

สร้างหน้า Admin Import ที่ล็อกอินได้ รองรับการลากไฟล์หลายไฟล์ แสดงตัวอย่างข้อความและ metadata ให้เจ้าหน้าที่แก้ไข แล้วส่งงานแปลงไฟล์ไปยังคิวเบื้องหลัง ก่อนให้ผู้มีอำนาจกดเผยแพร่ เอกสารต้นฉบับควรเก็บใน Supabase Storage หรือ object storage ที่กำหนดอายุและสิทธิการเข้าถึงได้

## หน้า Admin Import

เปิด `/admin/import` แล้วเข้าสู่ระบบด้วยค่าที่กำหนดใน `ADMIN_IMPORT_SECRET` การอัปโหลดจริงต้องตั้ง `SUPABASE_SECRET_KEY` บนเซิร์ฟเวอร์ด้วย คีย์ทั้งสองห้ามใช้คำนำหน้า `NEXT_PUBLIC_` และห้ามส่งไปยังเบราว์เซอร์ ดูรายการตัวแปรที่ต้องใช้ใน `web/.env.example`
